# README — short-video-fmcg-report

感谢使用本仓库。该仓库包含研究问卷与 PPT 内容（逐页稿与讲稿备注），以便你直接查看、复制并用 PowerPoint 制作最终演示文稿。

文件说明：
- short-video-questionnaire.md：可直接导入或复制到问卷平台的中文问卷题库（含实验模块说明）
- short-video-ppt-content.md：逐页 PPT 内容与讲稿备注，方便一键复制到 PowerPoint 并调整版式

关于 .pptx 文件：
- 当前环境中无法可靠地直接生成 PowerPoint 的二进制 .pptx 文件并保证格式完好。出于谨慎，我已将完整的 PPT 内容以 Markdown 格式上传，你可以用以下任一方式快速得到 .pptx：
  1) 在本地 PowerPoint 中，把 short-video-ppt-content.md 的每一节复制为一页幻灯片；将讲稿复制到“备注”栏；保存为 .pptx。
  2) 使用第三方工具（例如 Pandoc 或在线 Markdown-to-PPT 服务）将 Markdown 转换为 PPTX：
     - Pandoc 示例命令： pandoc -t pptx -o "短视频营销对快消品影响研究.pptx" short-video-ppt-content.md
     - 注意：转换后需要在 PowerPoint 中微调样式与图表。
  3) 如果你希望，我可以把内容另存为兼容 PPTX 的格式并再次上传（需要在会话中确认是否允许我创建仓库文件并继续）。
